## Security Principles

Security decisions follow a layered and proportional approach.

### Minimize Attack Surface
Systems should contain only the components required for their intended purpose.

### Separation of Concerns
Administrative, operational and testing functions should be separated where practical.

### Strong Authentication
Privileged access should use appropriate additional authentication factors.

### Protection of Data
Sensitive data should be protected both during storage and transmission.

### Independent Validation
Security controls should be tested independently where possible.

### Proportional Security
Security measures should reflect the actual risks, operational requirements
and available resources of the environment.
