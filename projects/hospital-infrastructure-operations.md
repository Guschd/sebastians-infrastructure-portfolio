# Hospital Infrastructure Operations

## Overview

Operation, maintenance and continuous improvement of a mission-critical hospital IT infrastructure supporting clinical and administrative services.

## Objective

Ensure high availability, security and reliability of the hospital's IT infrastructure while supporting day-to-day operations and future development.

## Responsibilities

- Infrastructure administration
- Windows Server administration
- Active Directory management
- VMware virtualization
- Enterprise networking
- User and permission management
- Monitoring and troubleshooting
- Technical documentation
- Procurement and system evaluation
- 1st & 2nd level support
- Vendor coordination

## Technologies

- Windows Server
- VMware ESXi
- Dell VxRail
- Active Directory
- Microsoft SQL Server
- HPE Aruba
- WatchGuard
- CheckMK
- Grafana

## Environment

- ~350 employees
- ~170 clients
- 120+ access points
- ~20 managed switches
- Multiple virtual servers
- Clinical information systems
- Medical network infrastructure

## Outcome

Reliable operation and continuous optimization of a highly available enterprise IT infrastructure supporting clinical workflows and patient care.
