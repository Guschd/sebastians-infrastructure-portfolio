# Hospital Infrastructure Modernization

## Overview

Multi-year infrastructure modernization project during the renovation of an operational hospital.

## Objective

Plan, coordinate and implement a modern, scalable and reliable IT infrastructure while maintaining uninterrupted clinical operations.

## Responsibilities

- Infrastructure planning
- Server room planning
- Structured cabling
- Enterprise network design
- VLAN concept
- Workplace planning
- Technical acceptance
- Invoice verification
- Coordination of architects, contractors and external IT service providers

## Technologies

- Windows Server
- VMware
- Active Directory
- HPE Aruba
- WatchGuard
- Enterprise WLAN

## Project Scope

- ~350 employees
- ~170 clients
- 120+ access points
- ~20 managed switches
- 2 server rooms
- 8 floor distributors

## Outcome

Successful planning and implementation of a modern IT infrastructure supporting future expansion, improved reliability and simplified maintenance.
