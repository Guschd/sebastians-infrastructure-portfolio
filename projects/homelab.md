# Enterprise Homelab

A self-designed enterprise-inspired laboratory environment used to evaluate technologies, validate infrastructure concepts and gain hands-on experience with enterprise solutions outside of production environments.

## Objectives

- Evaluate enterprise technologies
- Test infrastructure concepts
- Validate backup and recovery strategies
- Simulate production environments
- Improve documentation and automation skills

---

### Virtualization

- Proxmox VE
- Multiple virtual machines
- Snapshot management
- Scheduled backups

### Network

- WatchGuard Firebox T20
- AVM FRITZ!Box 6591 Cable
- Managed VLAN segmentation
- WireGuard VPN

- Enterprise firewall policies

### Services

- Home Assistant
- Jellyfin Media Server
- OpenMediaVault
- i-doit Documentation
- Debian Server
- Ubuntu Server

### Storage

- SSD & NVMe Storage

### Monitoring & Documentation

- Infrastructure documentation with i-doit
- Network topology documentation
- Asset management
- Change documentation
